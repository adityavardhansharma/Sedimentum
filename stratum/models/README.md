# holo-words.bin

Word meanings for Holo's recall (`Holo.Options.meaning`): 50,000 English
word stems, 300-dimension int8 vectors and 8 nearest neighbours each.

Built by `tools/export_words.py` from ConceptNet Numberbatch 19.08 (English),
https://github.com/commonsense/conceptnet-numberbatch. Numberbatch is
licensed CC BY-SA 4.0 (Speer, Chin and Havasi, "ConceptNet 5.5: An Open
Multilingual Graph of General Knowledge", AAAI 2017), and so is this file.
Word frequencies come from the `wordfreq` package.
